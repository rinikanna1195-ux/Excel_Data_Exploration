# 📊 Excel Data Exploration and Analysis

## 📌 Project Overview
This project focuses on basic data exploration and analysis using Microsoft Excel. The objective is to analyse a product dataset using Excel formulas, logical functions, conditional functions, and text functions.

## 🛠️ Tools Used
- Microsoft Excel
- Excel Formulas and Functions
- Data Exploration
- Data Analysis

## 📁 Dataset Description
The dataset contains 34 product records with the following columns:

- Product ID
- Product Name
- Brand Name
- Price
- Quantity
- Category
- Price Range
- Day
- Country Code
- Month

## 📈 Tasks Performed

### 1. Basic Data Exploration
- SUM – Calculate total product price.
- COUNTA – Count the number of products.
- AVERAGE – Calculate average product price.

### 2. Minimum and Maximum Values
- MIN – Identify minimum product price.
- MAX – Identify maximum product price.

### 3. Logical Function
- IF – Categorise products based on price.
- High Price: Price ≥ $500
- Standard Price: Price < $500

### 4. Conditional Functions
- SUMIF – Calculate total price of Electronics products.
- COUNTIF – Count products with a price below $100.

### 5. Text Functions
- LEFT – Extract Day from Product ID.
- RIGHT – Extract Country Code from Product ID.
- MID – Extract Month from Product ID.
